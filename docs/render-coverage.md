# Presentation and application coverage

This document compares the presentation subsystems of the retail engine (`xgameFinal.exe`, Halo
Wars DE) with the crates `render`, `net` and `motion` and the root executables. The engine
evidence is a function or a string address in the shared IDA database. "Missing" means that no code
in this repository implements the item.

For the simulation, see [simulation-coverage.md](simulation-coverage.md). For the terrain shaders,
see [hwde-shader-comparison.md](hwde-shader-comparison.md).

| Picking: screen rays, point projection, terrain ray march | `BUser_updateHover` @ `0x140581510` (hover point raycast) | `crates/render/src/picking.rs`. The march step is 1 world unit, then 16 bisection steps. |
| Mouse input: held, pressed and released buttons, wheel lines | `BUser_handleInputGame` @ `0x140590320` | `crates/render/src/input.rs`, `crates/render/src/input/state.rs`. A button release arrives even when egui uses it, so a drag that ends over the HUD ends. |
| Selection decals | `BSquad_drawSelectionDecal` @ `0x1403ABEA0`, `BDecalManager_renderDecalBatch` @ `0x1406F36A0`, `BTerrainHeightField_renderDecalPatches` @ `0x140666FC0` | `crates/render/src/selection_decals.rs`. Terrain-conforming patch of 2·`RadiusX` by 2·`RadiusZ` along the squad axes, drawn with the unlit `terrainHeightField` path in the HDR world pass: `rgb = tex.rgb² · color.rgb² · intensity · color.a`, `a = tex.a · color.a`, discard below `tex.a < 0.1`, source-alpha blend, depth test without depth write. Substitute art: retail takes the texture from the Flash UI decal movies (`hud_selection.gfx`, `hud_unsc_infantry.gfx`), which are vector art without a bitmap. The renderer generates a soft white ring (128 × 128 texels, peak at 0.85 of the radius) instead. The decal sits 0.25 world units above the terrain; the protosquad `YOffset` and the retail clamp to the center height are not applied. |
| HP bars | `BHPBar_renderSquadHPBar` @ `0x140044080`, `BHPBar_renderUnitHPBar` @ `0x140043530`, `BHPBar_drawSquadHPBarBatch` @ `0x140046F90` (`renderSquadHPBar` of `HPBar\HPBar.bin`) | `crates/render/src/hp_bars.rs`, `crates/render/src/hp_bars/`. Camera-facing world quad of `SizeX` by `SizeY` world units. The frame texture is tinted by the player selection color. Inside each fill rectangle, the mask alpha blends to the stage color on the filled part or to the grey (0.1, 0.1, 0.1, 0.5) on the empty part. Source-alpha blend, no depth test, after the tone mapping. The stage intensity is not used, as in retail. The game client must fill the instances. |
| Screen fades and game timers | trigger effects | `crates/render/src/ui/fades.rs`, `crates/render/src/ui/timers.rs` |
| Frame of a loaded scenario: shadow, scene, particle, distortion and tone-map passes | PC renderer frame | `crates/render/src/world_view.rs`. `terrain_viewer` and a future game client use the same `WorldView`. |
